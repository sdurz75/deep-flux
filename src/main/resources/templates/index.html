deep-flux

Genera immagini con l'aiuto di un assistente, ritrovale in galleria. Navigazione via HTML renderizzato dal server (Spring MVC + Thymeleaf), interattivita' locale con Alpine.js, aggiornamenti parziali via htmx. Nessuno step di build frontend.

  • Deep Chat — descrivi l'immagine che vuoi, l'assistente puo' cercare sul web e generarla su Replicate.
  • Genera immagine — form diretto: modello, prompt e parametri, senza chatbot.
  • Galleria — tutte le immagini generate, con prompt e modello usato.

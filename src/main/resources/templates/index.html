spring-htmx-starter

Webapp minimale: navigazione via HTML renderizzato dal server (Spring MVC + Thymeleaf), interattivita' locale con Alpine.js, aggiornamenti parziali via htmx. Nessuno step di build frontend.

Demo incluse

  • Load more — paginazione incrementale: l'endpoint restituisce solo i nuovi <li>, mai l'intera pagina.
  • Search — stessa URL, due risposte: fragment se la richiesta arriva da htmx, pagina intera altrimenti (vedi header HX-Request).

Per i dettagli su struttura, convenzioni e come estendere il progetto, vedi CLAUDE.md nella root del repository.
